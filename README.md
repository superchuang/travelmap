# 我的旅行手帳

純靜態旅遊回憶網站（HTML／CSS／JS），首頁是世界地圖，點圖釘或卡片就能翻開那趟旅程。

## 檔案說明

| 檔案 | 用途 | 需要改嗎？ |
|---|---|---|
| `index.html` | 首頁骨架 | 通常不用 |
| `data.js` | **所有旅程資料都在這裡** | ✅ 新增旅程改這個 |
| `style.css` | 外觀（顏色在最上面 `:root`） | 想換色再改 |
| `script.js` | 網站程式 | 不用 |
| `globe.js` | 3D 地球效果 | 不用 |
| `images/` | 照片 | ✅ 放你的照片 |
| `lib/` | 3D 地球、地圖套件、衛星影像、世界國界（全部內建，不需網路、不需金鑰） | 不用，**上傳時記得一起傳** |

## 新增一趟旅程

1. 照片放進 `images/`，檔名用英文和數字（例如 `osaka-1.jpg`），不要有空格
2. 打開 `data.js`，複製一整段 `{ ... }`，貼在最後一段後面，兩段之間用逗號隔開
3. 修改內容；經緯度可在 Google 地圖對地點按右鍵，點第一行數字就會複製
4. 存檔，重新整理網頁

想換出發地（航線的起點），改 `data.js` 最上面 `SITE` 裡的 `home`；不想要航線就刪掉那一行。

小提醒：手機拍的照片很大，建議先縮小到寬度約 1600px 再放進來，網頁會快很多。
範例的 `.svg` 佔位圖換成自己的照片後就可以刪掉。

## 在電腦上預覽

直接雙擊 `index.html` 用瀏覽器打開即可，地圖離線也能顯示。
首頁預設是 3D 地球：拖曳旋轉、點一下地球後可用滾輪縮放、點圖釘會飛過去再打開旅程；右上角可切換成平面地圖。
去過的國家會自動上色（依照每趟旅程的經緯度判斷）。

## 上傳到 GitHub Pages

1. 在 GitHub 建立新的 repository（設成 Public）
2. 按 **Add file → Upload files**，把整個資料夾的內容（`index.html`、`images/` 等）拖進去，按 Commit
3. 到 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 Save
4. 等一兩分鐘，網址會顯示在同一頁（像 `https://你的帳號.github.io/repo名稱/`）

注意：GitHub 上的檔名有分大小寫，`Photo.JPG` 和 `photo.jpg` 是不同檔案，`data.js` 裡要寫得一模一樣。
